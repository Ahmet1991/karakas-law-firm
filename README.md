# Karakaş Law Firm

Premium, bilingual (TR/EN), responsive static website for Karakaş Hukuk Bürosu.

## Structure
- `index.html` — single-page website
- `styles.css` — visual system and responsive layout
- `script.js` — language switcher, mobile menu and reveal animations
- `assets/favicon.svg` — site icon

## GitHub Pages
This project is intentionally dependency-free so it can be published directly from the `main` branch root using GitHub Pages.

Recommended Pages configuration:
1. Repository visibility: **Public** if using GitHub Free.
2. `Settings → Pages`
3. Source: **Deploy from a branch**
4. Branch: **main**
5. Folder: **/(root)**

## Content note
The website is drafted as an informational law-firm website. Before final production use, contact details, biography, professional-title wording, legal notices and compliance text should be confirmed by the firm.
